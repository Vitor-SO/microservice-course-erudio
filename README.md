<h1>Repositorio que representa o projeto feito durante o curso introdutorio de microsserviços</h1>
<h2>durante o curso foram utilizados as tecnologias:</h2>
<lu>
  <li> <bold>Spring Cloud Configuration</bold>: para centralizar e versionar configurações</li>

<li><bold>Spring Boot Actuator</bold>: para monitorar os serviços</li>

<li><bold>Feign</bold>: para comunicação entre microsserviços de forma simples</li>

<li><bold>Eureka</bold>: para service discovery e service registry</li>

<li><bold>Spring Cloud LoadBalancer</: para balanceamento de carga moderno</li>

<li><bold>Spring Cloud Gateway</bold>: para centralizar o tráfego com rotas flexíveis</li>

<li><bold>Resilience4J</bold>: para implementar circuit breaker e tornar os serviços mais resistentes</li>

<li><bold>Swagger OpenAPI</bold>: para documentar de forma clara e acessível</li>

<li><bold>Zipkin com Docker</bold>: para rastreamento de chamadas distribuídas</li>

<li><bold>GitHub Actions</bold>: para entrega contínua automatizada</li>

<li><bold>Kubernetes</bold>: para orquestrar os serviços e preparar seu projeto para produção real</li>
  </lu>
